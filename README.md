# Chess

A two-player chess game in HTML, CSS and JavaScript with a black-and-white 2D look.
The pieces are drawn as shapes (SVG), not letters or symbols.

## How to play

Open `index.html` in any web browser. Click one of your pieces to see where it can
move (dots show normal moves and rings show captures), then click a square to move there.

- Full rules: check, checkmate, stalemate, castling, en passant and pawn promotion
- Draws by insufficient material, the 50-move rule and threefold repetition
- **Undo** takes back a move, **Flip board** turns the board around, **New game** starts over

## Play online with GitHub Pages

In the repository go to **Settings → Pages**, choose "Deploy from a branch", pick your
branch and the `/ (root)` folder, and save. GitHub will give you a link to play in the browser.
